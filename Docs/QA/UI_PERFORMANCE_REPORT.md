# Отчёт производительности RTS UI

Дата: 20 августа 2026 года  
Сборка: Unreal Engine 5.8.1, macOS, Apple M4 Max, Development Editor  
Разрешение: 1672×941, off-screen render

## Мини-карта

Замер сделан внутри `SRA4Minimap::OnPaint` на первом реальном проходе Slate. Контакты передавались одним неизменяемым массивом. Для каждого контакта не создаётся `UWidget` или `SWidget`.

| Контакты | Время первого Paint | Draw elements | Виджеты контактов |
|---:|---:|---:|---:|
| 0 | 5,83 мкс | 14 | 0 |
| 200 | 15,25 мкс | 214 | 0 |
| 1 000 | 58,08 мкс | 1 014 | 0 |
| 5 000 | 224,66 мкс | 5 014 | 0 |

Результат: время растёт линейно, но даже 5 000 контактов занимают меньше 0,23 мс на измеренной машине. Память под отдельные виджеты не выделяется. Слой инвалидируется только при новой сводке, изменении рамки камеры или размера карты.

## Мировые маркеры

Полосы здоровья, рамки выделения и состояние разведки также рисуются одним `SRA4WorldMarkerLayer`. Скрытые разведкой противники отбрасываются до отрисовки. Цвет здоровья и символ команды определяются без создания дочерних виджетов.

## Ограничения замера

Это локальный замер первого прохода Paint, а не полный GPU-профиль кадра. Перед релизной оптимизацией его нужно повторить на целевых Windows-машинах и консолях в Unreal Insights вместе с реальной картой и материалами.
