# Визуальная приёмка интерфейса RA4

Дата проверки: 20 августа 2026 года
Движок: Unreal Engine 5.8.1, Development Editor, macOS
Основное разрешение: 1672×941
Дополнительная проверка HUD: 3440×1440

## Результат

Все 24 референса открыты и сняты непосредственно в Unreal. Пустых экранов, перепутанных маршрутов,
критических перекрытий и экранов-картинок без реальных элементов управления не обнаружено.

Критические различия: 0.
Крупные различия: 0.
Мелкие различия: художественные детали не копируют исходные материалы попиксельно, но сохраняют
тот же состав, масштаб и визуальный акцент. Интерфейс остаётся полностью живым и интерактивным.

## Что проверено

- Экранные пропорции, безопасные поля и отсутствие обрезки обязательных элементов.
- Реальные кнопки, списки, полосы прогресса, карточки производства и поля ввода.
- Портретные сцены кампаний, карта Евразии, киевский экран загрузки и фракционные иконки юнитов.
- Разные темы СССР, Альянса, Восточной коалиции и Хронолегиона.
- Девять отдельных HUD-состояний при одном общем событийном HUD-каркасе.
- Центр игрового мира пропускает команды; панели HUD блокируют ввод только в своих границах.
- Мини-карта и мировые отметки рисуются пакетно без отдельных виджетов на каждый контакт.
- Контрольный ультраширокий проход HUD на 3440×1440.

## Автоматические ворота

`Tools/Editor/ValidateRA4UI.py` подтвердил: 24 контракта, 24 Widget Blueprint и 4 темы. Скрипт
проверяет существование ресурсов, родительский класс, вариант, номер референса, назначенный фон и
компиляцию Blueprint.

В журнале запуска остаётся известное общепроектное предупреждение `GameFeatureData`, не связанное
с интерфейсом. Валидатор завершился с кодом 0 и строкой `RA4 UI VALIDATION PASSED`.

Автоматический набор `RA4.UI` выполнил 23 проверки без ошибок. Отдельная CMake-проверка выполнила
4 набора тестов без падений.
