# Аудит сторонних паков в `Content/ThirdParty/`

Проведён 2026-08-06 при разборе задачи V-6. Проверялось запуском команд, не чтением
документов.

## Как проверялось

```sh
# Наличие в реестре лицензий
for d in Content/ThirdParty/*/; do grep -ic "$(basename $d)" Docs/Production/LEGAL_AND_LICENSES.md; done

# Отслеживается ли в git
git ls-files Content/ThirdParty/

# Ссылается ли на пак карта или код
grep -rl "FactoryEnvironment" Source/ Tools/ Config/ Content/RA4/
grep -ac "FactoryEnvironment" Content/Maps/*.umap
```

Ни в одном паке нет файла лицензии внутри каталога.

## Две проблемы, найденные попутно

### 1. Юридическая: 12+ ГБ ассетов вне реестра

`LEGAL_AND_LICENSES.md` подробно описывает шрифты, звуки и CC0-текстуры, но не
содержит ни одного из четырёх крупных паков. CLAUDE.md запрещает использование
нелицензированных ассетов, а `Docs/QA/RELEASE_CRITERIA.md` требует чистого
юридического аудита перед релизом. Сейчас происхождение и права на CityPark,
QuantumCharacter и IndustryPropsPack6 не зафиксированы нигде.

Это блокирует коммерческий выпуск и требует решения владельца проекта: указать
источник и лицензию каждого пака либо заменить их.

### 2. Воспроизводимость: карта зависит от пака, которого нет в git

`Tools/Editor/make_archipelago_map.py` содержит 16 ссылок на `/Game/ThirdParty/CityPark/`
— деревья, камни, дороги, мосты. Пак при этом не отслеживается git. Свежий клон
репозитория соберёт карту без растительности и без дорог, и генератор не сообщит об
ошибке, потому что `spawn_mesh` молча пропускает отсутствующий меш.

## Что сделано по V-6

`FactoryEnvironment` перемещён из `Content/` в карантин и добавлен в `.gitignore`.
Он не был в git, на него не ссылается ни одна карта, ни один материал и ни один
файл исходников — проверено grep по `Source/`, `Tools/`, `Config/`, `Content/RA4/`
и побайтовым поиском по всем шести `.umap`.

Измеренный эффект на полном прогоне
`ResavePackages -verify` по 13 435 пакетам:

| | до | после |
| :--- | ---: | ---: |
| ошибок | 212 | **4** |
| упоминаний FactoryEnvironment | 208 | **0** |

Оставшиеся четыре не относятся к контенту проекта:

- `HttpListener unable to bind to 127.0.0.1:8000` — порт занят другим экземпляром;
- `Unexpected custom version "FortniteMain"` в `/Engine/Tutorial/Audio/TutorialTest` — ассет движка;
- `Asset manager settings do not include a rule for GameFeatureData` — предупреждение подсистемы;
- та же запись о диспетчере ресурсов в русской локали.

Пак перемещён, а не удалён: 7 ГБ лежат в `/tmp/fe_quarantine/FactoryEnvironment`
до решения владельца. `/tmp` очищается системой, поэтому если пак нужен —
перенесите его в постоянное место.

## Не сделано

Реестр лицензий намеренно не правился: вписать «источник неизвестен» в юридический
документ хуже, чем оставить пробел видимым. Нужны фактические данные о покупке или
источнике каждого пака.
