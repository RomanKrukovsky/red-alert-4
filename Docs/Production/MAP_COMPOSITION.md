# Композиция карты RA4_Skirmish_Production

## Проблема

Оценка владельца проекта: «ассеты раскиданы хаотично без логики». Оценка верная.
Прежнее размещение было арифметикой, выданной за левел-дизайн.

## Что исправлено в `Tools/Editor/make_archipelago_map.py`

### Базы

Было: пять зданий по углам квадрата 400×400, одинаково для обоих игроков и без
поворота — ничто не указывало, куда база «смотрит».

Стало: здания стоят на оси, повёрнутой лицом к центру карты (`BASE_LAYOUT`,
`base_frame`):

| Позиция | Здание | Причина |
| :-- | :-- | :-- |
| фронт | WarFactory, Barracks | юниты выходят в сторону боя |
| центр | ConYard | опорная точка застройки |
| тыл | PowerPlant | уязвим, его прикрывают |
| дальний тыл | Refinery | ближе к руде, которую обслуживает |

Смещения асимметричны намеренно: ни одна пара зданий не делит X или Y, поэтому
читается композиция, а не сетка. Здания повёрнуты по оси базы — строение,
поставленное боком к своей же подъездной дороге, выглядит «уронённым».

### Руда

Было: `(±500, ±500)` от центра базы — внутри периметра, по диагонали, без
конкуренции. Доход без решения.

Стало: восемь сгруппированных пятен (`ORE_PATCHES`), заданных островом и углом:
один безопасный домашний патч на игрока, два спорных на центральном острове,
четыре на спутниках. Экономика превращается в вопрос контроля карты. Каждое пятно
— несколько камней с разным масштабом и поворотом, а не один растянутый куб.

### Дороги

Было: отдельные меши, состыкованные подряд. Любое округление масштаба даёт
видимый шов, а на изгибе маршрут распадается на прямые плиты.

Стало: ландшафтные сплайны (`build_spline_road`) — непрерывные по построению.
Маршрут (`route_points`) идёт от въезда базы тремя точками с изгибом, поэтому
дорога обходит остров и пересекает воду ближе к перпендикуляру. Плиточный путь
сохранён как резерв и включается автоматически, если API сплайнов недоступен, —
карта никогда не остаётся без связей.

## Проверка

Редактор не был запущен, поэтому геометрия проверена расчётом:

- обе базы дают одинаковые дистанции до центра — 5043 / 5187 / 5657 / 6051 / 6226,
  то есть расстановка симметрична и конкурентно честна;
- WarFactory ближе к центру, чем Refinery, у обеих сторон — ось развёрнута верно;
- руда: домашние патчи по 1364 uu, центральные действительно спорные, спутники
  разделены по два на игрока (5005/5275 против 5046/5249), ни один не вне карты.

## Что ещё не сделано

Изменён только генератор. В `.umap` это не применено: нужен сеанс редактора.

`load_level` нельзя вызывать через MCP — он выгружает мир, после чего мост
отвечает против `world: None`. Карту следует открывать штатно, до запуска
генератора.
