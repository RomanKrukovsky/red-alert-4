# Blockout replacement — отчёт вертикального среза

Дата проверки: 2026-08-02

Ветка: `codex/art-blockout-replacement`

Unreal Engine: 5.8.1 (фактическая версия установленного проекта)

## Итог

Подготовлен первый воспроизводимый вертикальный срез: 36 из 142 старых блок-аутов заменены новыми редактируемыми моделями. Это по девять основных объектов для каждой из четырёх фракций: штаб, электростанция, переработчик, казармы, военный завод, харвестер, разведчик, основной танк и артиллерия.

Статус этих 36 моделей: `GENERATED_DRAFT`. Они уже пригодны для проверки масштаба, силуэта, фракционной читаемости, материалов и интеграции, но ещё не являются финальным production-art.

Оставшиеся 106 блок-аутов не удалялись и продолжают работать как резервный контент.

## Что сделано

- Полный инвентарь 142 старых Static Mesh с фактическими путями, размерами, LOD, коллизиями, сокетами и ссылками.
- Единый manifest на 36 Stable ID из игрового контента.
- Детерминированная Blender 5.1 pipeline: генерация `.blend`, экспорт FBX, импорт и проверка в Unreal.
- Для каждой модели сохранён редактируемый `.blend` и четыре FBX: LOD0–LOD3.
- В Unreal импортированы 36 новых Static Mesh. У каждого четыре LOD, простая коллизия и обязательные сокеты.
- Создан PBR master-material на основе ambientCG PaintedMetal006 и фракционные material instances.
- Созданы дневная и ночная showcase-карты со всеми 36 моделями.
- Реестр игровых визуалов переведён на новые ассеты для этих 36 Stable ID; старый реестр сохранён как fallback.
- Исправлена скрытая runtime-подмена материалов: нативный `BasicShapeMaterial` переживал замену меша как component override. Теперь игровые акторы явно восстанавливают авторские material slots.
- Презентационный слой менялся без изменений детерминированной симуляции.

## Фактические результаты проверки

- Inventory: 142 Static Mesh; Soviet 35, Alliance 36, Coalition 36, Chronolegion 35.
- До замены: у всех 142 был только один LOD; подтверждённых сокетов не было.
- Источники: 36 `.blend`.
- Экспорт: 144 `.fbx`.
- Unreal import report: 36 imported, 0 blocked.
- Unreal validation report: 36 validated, 0 blocked.
- Сборка `RedAlert4Editor Mac Development`: успешно.
- Живой запуск `RA4_Skirmish`: успешно. В логе штаб, переработчик и харвестер используют `MI_RA4_Surface_Soviet`, а не `BasicShapeMaterial`.
- Showcase: обе карты создаются повторным запуском скрипта; дневная сцена содержит 42 актора, включая все 36 моделей, свет, атмосферу, туман, землю и камеру.
- Cook трёх проверочных карт: выполняется отдельно с `-SkipZenStore`; итог записывается после завершения проверки.

Отчёты проверки лежат в:

- `Saved/Reports/BlockoutReplacementInventory.json`
- `Saved/Reports/ModelImportReport.json`
- `Saved/Reports/ModelValidationReport.json`

## Что остаётся

- 106 из 142 моделей всё ещё блок-ауты.
- Геометрия первой партии процедурная и требует ручного художественного прохода: фаски, нормали, плотность деталей, декали, загрязнение и повреждения.
- Техника пока импортирована как Static Mesh. Башни, колёса и гусеницы разделены в `.blend`, но runtime-анимация этих частей ещё не подключена.
- Нет скелетов, ригов и боевых/смертельных анимаций для этой партии.
- Нет финальных разрушенных вариантов и фракционных decal-mask для цвета конкретного игрока.
- Материалы хорошо различают фракции в тестовой сцене, но требуют финального баланса экспозиции и roughness в боевой карте.
- Hardcoded visual registry остаётся техническим долгом; следующим шагом его следует полностью перенести в проверяемый Data Asset без изменения simulation layer.
- Headless-набор проекта сейчас не собирается из-за существующей до этой ветки зависимости `RA4FogOfWar/Public/FogOfWarGrid.h` от `CoreMinimal.h`. Поэтому тесты и побайтовое сравнение `RA4MatchDump` в этой ветке честно не подтверждены. Арт-изменения этот модуль не затрагивают.

## Повторение pipeline

Скрипты запускаются по порядку:

1. `Tools/Art/inventory_blockouts.py`
2. `Tools/Art/generate_models.py`
3. `Tools/Art/export_models.py`
4. `Tools/Art/create_materials.py` в Unreal Editor
5. `Tools/Art/import_models.py` в Unreal Editor
6. `Tools/Art/create_showcase.py` в Unreal Editor
7. `Tools/Art/validate_models.py` в Unreal Editor

Повторный запуск не требует удаления старых ассетов и создаёт те же имена, пути, Stable ID, LOD и сокеты.
