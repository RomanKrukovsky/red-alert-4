# ADR-010: UE5 Presentation Layer Decoupling

## Status
Accepted

## Context
High-performance RTS requires rendering thousands of units without binding simulation state directly to heavy `AActor` components.

## Decision
1. **Model-View Decoupling**: Visual components in `RA4Presentation` and `RA4UI` observe simulation snapshots generated by `SimWorld`.
2. **Slate & CommonUI**: UMG and Slate UI elements bind strictly to snapshot getters (`GetCredits()`, `GetPower()`, `GetSelection()`) rather than polling internal simulation objects directly.
