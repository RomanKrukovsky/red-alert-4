# ADR-0010: 2-Minute Spectator Delay Buffer for Anti-Ghosting

## Context
Live streaming of competitive 1v1 ladder matches allows third parties to communicate enemy position and fog-of-war details (stream ghosting).

## Decision
Enforce a mandatory 2-minute spectator delay buffer (7,200 ticks) for all public live spectator streams.

## Rationale
- Prevents stream ghosting while preserving real-time eSports broadcast commentary capability.
