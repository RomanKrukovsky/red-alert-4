# Moved: ADR-0011 (DirectControl) is now ADR-0029

This decision record lives at
[`ADR-0029-direct-control.md`](ADR-0029-direct-control.md).

It was renumbered on 2026-08-20 because it shared the number ADR-0011 with
[`ADR-0011-adr-series-consolidation.md`](ADR-0011-adr-series-consolidation.md),
which is the ADR that set out to end duplicate numbering in the first place. That
collision was recorded in NEXT_ACTIONS P-3 and in ADR-0011's own errata; both
prescribed ADR-0028 as the new number, but ADR-0028 was taken by the telemetry
ADRs before the rename happened, so the document became ADR-0029.

This stub exists because "ADR-0011" is cited by number in source headers and in
other ADRs written before the rename. Those citations were updated, but a
reference in a document not in this repository — a report, a message, a branch
not yet merged — has nowhere else to land.

**ADR-0011 now means only the ADR series consolidation decision.**
