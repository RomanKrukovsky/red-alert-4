# Warzone 2100 — что взято и на каких условиях

Warzone 2100 — RTS 1999 года, открытая с 2004-го под GPL, с 25-летней историей
публичной разработки. Ценность для RA4 не в её коде: ценность в том, что это
единственная доступная нам RTS сопоставимой сложности, у которой **видно, как
именно оно сломалось и чем чинилось**. Такого материала не даёт ни одна закрытая
игра и ни одна статья.

## Лицензионная стена

Warzone 2100 под GPL. RA4 проприетарный. Это несовместимо, и стена проходит не
по «мы аккуратно перепишем», а по границе идея/выражение.

**Не переносится ничего из этого:**

- файлы и фрагменты файлов, включая переписанные «своими словами» функции;
- таблицы статов — `data/**/*.json`, `*.ini`, `stats/*`. Это данные под GPL;
- ассеты, карты, звук, тексты;
- иерархия классов один-в-один;
- их конструктор юнитов (корпус + шасси + башня). Тут даже не лицензия — RA4
  просто не про это.

**Переносится только это:**

- факты о том, где ломался детерминизм (факт не охраняется авторским правом);
- форма интерфейса: какой минимальный набор событий и запросов нужен, чтобы
  миссия писалась данными, а не компиляцией;
- дизайнерские решения как решения — «непрямой огонь требует наводчика» это
  правило игры, а не текст программы;
- структура механизма, отделённая от значений: «урон = база × множитель из
  таблицы класс×класс» — структура; сами множители — данные под GPL.

Ни один документ в этой папке не содержит их кода и их чисел. Числа для RA4
берутся из библии RA4.

## Как это читать

Документы называют состояние RA4 на 2026-08-04 и говорят, чего у нас нет. Там,
где RA4 уже сделал то же самое (матрица warhead×armor, `MinRange` у артиллерии),
это сказано прямо, чтобы разбор не выдавал сделанное за задачу.
