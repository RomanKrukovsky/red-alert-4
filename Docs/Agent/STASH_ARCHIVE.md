# Stash Archive

Every `git stash` entry in this repository was tagged before any stash cleanup, so
its contents survive independently of the stash reflog. Stashes are fragile: a
single `git stash clear`, or a GUI "discard" action, deletes them permanently and
they are not reachable from any branch.

This mattered concretely: the whole `RA4Intel` module (~2558 lines, 6 ADRs, 352
lines of tests) existed *only* inside `stash@{0}` and was in no commit on any
branch. It is now committed properly on `main` via `f75cf3e`.

## How to inspect or recover one

```sh
git show --stat archive/stash-N          # what is inside
git show archive/stash-N -- path/to/file # one file's contents
git stash apply archive/stash-N          # apply as a copy (does not consume it)
```

Prefer `apply` over `pop`; these tags are the safety net, so leave them intact.
